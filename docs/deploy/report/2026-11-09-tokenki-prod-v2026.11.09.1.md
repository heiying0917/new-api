## 已知缺口（本次代码，待决定是否跟进）
带亲和键但未命中亲和（会话首轮，或亲和渠道满载 / 冷却改走正常选路）的请求，重试回到同一渠道时会再次选中同一把 key（429 冷却除外）。某个 region 单独故障（非 429、不触发自动禁用）时，这类请求的渠道内重试会反复打同一个 region，旧逻辑则随机换 region。亲和命中的请求在默认 claude cli trace 规则下不重试（SkipRetryOnFailure），不受影响。修法：重试时避开本请求已失败过的 key。
