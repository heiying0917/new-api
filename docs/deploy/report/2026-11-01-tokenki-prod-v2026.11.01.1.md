## 发现
1. **手动测试自动禁用不生效（本版新功能缺陷）**：`testChannel` 上游失败时同时返回 `localErr` 与 `newAPIError`，`TestChannel` 先判 `localErr` 提前返回，未调用 `disableChannelOnTestFailure`；原单测直接调用该函数，绕过了真实路径。影响：手动测试仍不触发自动禁用（与发版前一致），无回归。已在本地修复并补走完整 `TestChannel` 接口的回归测试（反向验证：撤销修复即失败），待提交。
2. **#112 手动测试报错未禁用（用户反馈）**：默认测试模型为模型列表首个 `claude-haiku-4-5`，报 `400 The provided model identifier is invalid`；改测 `claude-opus-4-6` 成功，真实流量也正常，渠道健康——按规则「模型 ID 无效」不因手动测试禁用，**不禁用是正确的**。根因是 `relay/channel/aws/constants.go` 将别名 `claude-haiku-4-5` 映射为不存在的 `anthropic.claude-haiku-4-5`（09-17 Claude 5 模型表提交引入）。近 7 天真实流量无该报错，无渠道受影响。已在本地改为 `anthropic.claude-haiku-4-5-20251001-v1:0` 并补测试，待提交。同批别名中 opus-4-7/4-8/opus-5 返回「该账号无权使用」（ID 被 Bedrock 识别），sonnet-5/fable-5-1 因未配价格无法测试。
